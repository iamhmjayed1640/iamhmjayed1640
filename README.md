## 🧪 Current Research

### 🌾 Cross-Domain Few-Shot Rice Disease Classification

A research project focused on **few-shot rice leaf disease classification across different domains**.

The work explores:

* Few-Shot Learning
* Prototypical Networks
* Attention-enhanced feature extraction
* Cross-domain generalization
* Metric learning
* Data diversity and augmentation
* Domain shift analysis
* Feature representation learning

The broader goal is to develop an AI-based approach that can identify rice diseases even when only a limited number of labeled examples are available.

### 🐔 Scale-Invariant Vision-Based Broiler Chicken Weight & Market Price Estimation

A computer vision project using **YOLO-based instance segmentation** to estimate broiler chicken weight and corresponding market price.

**Key components:**

* YOLOv11 Instance Segmentation
* Object detection and segmentation
* Mask and shape analysis
* Image-based feature extraction
* Weight estimation
* Market price estimation
* Video inference and deployment

The project also explores scale and perspective-related challenges for practical deployment using cameras, mobile devices, or CCTV systems.

---

### 🧠 Bengali Medical NLP with PEFT

A research-oriented Natural Language Processing project for classifying Bengali medical text and symptoms.

**Explored technologies:**

* Bengali NLP
* BanglaBERT
* mBERT
* XLM-R
* LoRA
* QLoRA
* Parameter-Efficient Fine-Tuning
* SHAP / LIME based explainability

The objective is to investigate efficient medical text classification approaches for low-resource Bengali language settings while considering computational constraints.
