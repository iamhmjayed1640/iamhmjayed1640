## 🏗️ Current Research & Key AI Projects

### 🌾 Cross-Domain Few-Shot Rice Disease Classification
A research project focused on classifying rice leaf diseases using few-shot learning across different domains. 
- **Explores:** Prototypical Networks, Attention-enhanced feature extraction, Cross-domain generalization, Domain shift analysis.

### 🌱 JB AgriAI
An AI-powered agricultural application bringing my research into a practical deployment environment.
- **Focus:** Rice leaf disease classification, Computer Vision, Prototype-based prediction. Users can upload crop images for AI-based disease prediction.

### 🐔 Vision-Based Broiler Chicken Weight & Price Estimation
A computer vision project using **YOLOv11** instance segmentation to estimate broiler chicken weight and market price.
- **Key Components:** Object detection & segmentation, Mask/shape analysis, Video inference. Explores scale and perspective challenges for real-world camera deployment.

### 🧠 Bengali Medical NLP with PEFT
A research-oriented NLP project for classifying Bengali medical text and symptoms.
- **Technologies:** BanglaBERT, mBERT, XLM-R, LoRA, QLoRA, SHAP/LIME. Investigates efficient classification for low-resource languages under computational constraints.
